# リスト内要素の編集

---

## リスト内要素を並べ替える

### sorted関数を使用して並べ替える

```python
numbers = [3, 1, 4, 1, 5]
print(f"元のリスト：{numbers}")

# ソートして表示
sorted_numbers = sorted(numbers)
print(f"昇順にソート：{sorted_numbers}")

# 降順にソートして表示
sorted_numbers = sorted(numbers, reverse=True)
print(f"降順にソート：{sorted_numbers}")
```

### 実行結果

> 元のリスト：[3, 1, 4, 1, 5]  \
  昇順にソート：[1, 1, 3, 4, 5]  \
  降順にソート：[5, 4, 3, 1, 1]

---

### sortメソッドを使用して並べ替える

```python
numbers = [3, 1, 4, 1, 5]
print(f"元のリスト：{numbers}")

# ソートして表示
numbers.sort()
print(f"昇順にソート：{numbers}")

# 降順にソートして表示
numbers.sort(reverse=True)
print(f"降順にソート：{numbers}")
```

### 実行結果

> 元のリスト：[3, 1, 4, 1, 5]  \
  [1, 1, 3, 4, 5]  \
  [5, 4, 3, 1, 1]

---

## リスト内要素の桁数を揃える

### 最大桁数の取得と文字列変換で桁数を揃える

```python
numbers = [1, 12, 123, 1234]
print(f"元のリスト：{numbers}")

max_digits = max(len(str(n)) for n in numbers)
print(f"最大桁数：{max_digits}")

formatted_numbers = [str(n).rjust(max_digits, "0") for n in numbers]
print(f"最大桁数に桁合わせ：{formatted_numbers}")

# 再度数字に戻す場合
reformatted_numbers = [int(n) for n in formatted_numbers]
print(f"元に戻す：{reformatted_numbers}")
```

### 実行結果

> 元のリスト：[1, 12, 123, 1234]  \
  最大桁数：4  \
  最大桁数に桁合わせ：['0001', '0012', '0123', '1234']  \
  元に戻す：[1, 12, 123, 1234]
---

### format関数を使用して桁数を揃える

```python
numbers = [1, 12, 123, 1234]
print(f"元のリスト：{numbers}")

formatted_numbers = [format(x, "4d") for x in numbers]
print(f"4桁に揃える：{formatted_numbers}")
```

### 実行結果

> 元のリスト：[1, 12, 123, 1234]  \
  4桁に揃える：['&nbsp;&nbsp;&nbsp;1', '&nbsp;&nbsp;12', '&nbsp;123', '1234']

---

### rjustメソッドを使用して桁数を揃える

```python
numbers = [1, 12, 123, 1234]
print(f"元のリスト：{numbers}")

formatted_numbers = [str(x).rjust(4, " ") for x in numbers]
print(f"4桁に揃える：{formatted_numbers}")
```

### 実行結果

> 元のリスト：[1, 12, 123, 1234]  \
  4桁に揃える：['&nbsp;&nbsp;&nbsp;1', '&nbsp;&nbsp;12', '&nbsp;123', '1234']
